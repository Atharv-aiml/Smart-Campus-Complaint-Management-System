## 🎯 Overview

> **Smart Campus Complaint Management System** is an enterprise-patterned, full-stack **Java desktop application** that replaces physical complaint registers at VIT Bhopal University with a smart, auditable digital workflow — connecting students with campus maintenance authorities at the click of a button.

<table>
<tr>
<td width="50%">

### 🔥 What Makes This Special
- 🏛️ **4-Tier Layered Architecture** — clean separation across Presentation, Business Logic, Repository, and Storage
- ⚡ **Zero Database Setup** — runs instantly using atomic Java Object Serialization (`.dat` files)
- 🎨 **Modern Custom Swing UI** — dark-themed, card-based layouts with custom `UITheme` design tokens
- 🧬 **Full OOP Coverage** — demonstrates all 15 core Java OOP concepts in real, meaningful code
- 🔒 **Role-Based Access Control** — completely separate dashboards for Students and Administrators
- 📊 **Live Analytics Engine** — real-time KPI metrics, resolution rates, category breakdown meters

<div align="center">

```

| 🏷️ Java Concept | 📁 Source File(s) | 🔬 Concrete Implementation |
|:---|:---|:---|
| 🧱 **Classes & Objects** | `model/User.java`, `model/Complaint.java` | Domain entities representing real-world campus entities |
| 🔒 **Encapsulation** | `User.java`, `Complaint.java` | Private fields, validated setters, immutable audit timestamps |
| 🧬 **Inheritance** | `Student.java`, `Admin.java` | Both extend abstract `User.java`, reusing identity + auth state |

└─────────────────────────────────────────────────────────────────────────────────┘

     ╔═══════════════════════════════════════════════════════════════════════╗
     ║                    🖥️  TIER 1: PRESENTATION LAYER                   ║
     ║                      (Java Swing with UITheme.java)                  ║
     ║  ┌───────────────┐  ┌─────────────────┐  ┌────────────────────────┐ ║
     ║  │  LoginFrame   │  │ StudentDashboard │  │   AdminDashboardFrame  │ ║
     ║  └───────────────┘  └─────────────────┘  └────────────────────────┘ ║
     ║  ┌───────────────┐  ┌─────────────────┐  ┌────────────────────────┐ ║
     ║  │ RegisterDialog│  │ComplaintDetails │  │    AnalyticsPanel      │ ║
     ║  └───────────────┘  └─────────────────┘  └────────────────────────┘ ║
     ╚═══════════════════════════════╦═══════════════════════════════════════╝
                                     ║  calls
     ╔═══════════════════════════════▼═══════════════════════════════════════╗
     ║                ⚙️  TIER 2: BUSINESS LOGIC / SERVICE LAYER            ║
     ║  ┌──────────────┐  ┌──────────────────┐  ┌──────────────────────┐   ║
     ║  │  AuthService │  │ ComplaintService  │  │    ReportService     │   ║
     ║  └──────────────┘  └──────────────────┘  └──────────────────────┘   ║
     ║  ┌────────────────────┐  ┌──────────────────────────────────────┐   ║
     ║  │  InputValidator    │  │         DataInitializer              │   ║
     ║  └────────────────────┘  └──────────────────────────────────────┘   ║
     ╚═══════════════════════════════╦═══════════════════════════════════════╝
                                     ║  delegates
     ╔═══════════════════════════════▼═══════════════════════════════════════╗
     ║               🗄️  TIER 3: REPOSITORY / DATA ACCESS LAYER            ║
     ║  ┌──────────────────────────────────────────────────────────────┐   ║
     ║  │  «interface» Repository<T, ID>  ←  FileRepository<T, ID>    │   ║
     ║  └──────────────────────────────────────────────────────────────┘   ║
     ║  ┌────────────────┐  ┌──────────────────┐  ┌──────────────────┐   ║
     ║  │StudentRepository│  │ AdminRepository  │  │ComplaintRepository│  ║
     ║  └────────────────┘  └──────────────────┘  └──────────────────┘   ║
     ╚═══════════════════════════════╦═══════════════════════════════════════╝
                                     ║  reads/writes
     ╔═══════════════════════════════▼═══════════════════════════════════════╗
     ║                  💽  TIER 4: PERSISTENT STORAGE LAYER               ║
     ║        📄 data/students.dat      📄 data/admins.dat                  ║
     ║                     📄 data/complaints.dat                            ║
     ║                    (Thread-safe Atomic I/O Writes)                    ║
     ╚═══════════════════════════════════════════════════════════════════════╝
```

## 🚀 Quick Start

### Prerequisites

```bash
# Verify Java 17+ is installed
java -version      # Expected: openjdk 17.x.x or higher
javac -version     # Expected: javac 17.x.x or higher
```

### ⚡ Option A — 1-Click Shell Scripts (Recommended)

```bash
# 1️⃣  Clone the repository
git clone https://github.com/Atharv-aiml/Smart-Campus-Complaint-Management-System.git
cd Smart-Campus-Complaint-Management-System

# 2️⃣  Compile all Java sources
./compile.sh

# 3️⃣  Launch the application 🚀
./run.sh

# 4️⃣  Run automated test suite 🧪
./test.sh
```

### 🔧 Option B — Maven Build

```bash
mvn compile
mvn exec:java -Dexec.mainClass="main.Main"
```

### 🖥️ Option C — Import into Your IDE

```
IntelliJ IDEA  →  File > Open > Select project root  →  Run 'main.Main'
Eclipse        →  File > Import > Maven Project  →  Run 'src/main/Main.java'
VS Code        →  Open Folder > Install Java Extension Pack  →  Run Main.java
NetBeans       →  File > Open Project > Select pom.xml  →  Run project
```

> **💡 Tip:** The app auto-seeds realistic demo data on first launch. No manual data entry needed!
